# Aura — Product Requirements Document

**Статус:** утверждён к реализации v1
**Дата:** 2026-08-26
**Владелец:** единственный пользователь — владелец машины

---

## 1. Одной строкой

Голосовой фронтенд к Claude Code и Codex: спит в трее, просыпается на кодовое
слово, принимает задачу голосом, ставит её агенту, озвучивает ход работы и итог.

## 2. Проблема

Агентные CLI работают минутами. Всё это время разработчик привязан к терминалу:
чтобы понять, движется ли агент, надо смотреть в поток. Постановка задачи требует
переключения контекста — найти окно, вспомнить путь, набрать промпт. Итог работы
приходит простынёй markdown, из которой нужно ещё вычитать суть.

Три следствия:

1. Задачи, которые можно было бы поставить «между делом», не ставятся вовсе.
2. Ожидание агента — мёртвое время, потому что уйти нельзя.
3. Ошибку агента замечают поздно — когда он уже сделал лишнее.

## 3. Пользователь

Один. Владелец машины, разработчик, работает на ноутбуке Windows 11, часто от
батареи. Говорит по-русски с английскими техническими терминами; иногда хочет
полностью английский режим. Не готов терпеть заметный расход батареи ради удобства.

## 4. Задачи пользователя (jobs to be done)

| # | Задача | Как выглядит успех |
|---|---|---|
| J1 | Поставить агенту задачу, не касаясь клавиатуры | сказал — задача ушла, подтверждение голосом |
| J2 | Понимать ход работы, не глядя в терминал | слышно, что происходит, без бубнежа |
| J3 | Узнать итог, не читая вывод | 2–3 фразы по делу |
| J4 | Остановить агента, когда он пошёл не туда | стоп-слово работает **во время** озвучки |
| J5 | Решить судьбу опасного действия голосом | вопрос вслух, ответ «да/нет», отказ по таймауту |
| J6 | Уточнить задачу на ходу | реплика уходит в живую сессию без холодного старта |

## 5. Сценарии

**S1. Постановка задачи.**
«Аура» → звук готовности → «в проекте backend почини падающие тесты в auth-модуле»
→ Aura отвечает «Клод взялся, проект backend» → работа пошла.

**S2. Ход работы.**
Через 8 секунд: «запускаю тесты». Через 6 секунд: «один тест упал — проверка срока
токена». Через 5 секунд: «починил, четыре из четырёх зелёные».

**S3. Опасное действие.**
«Клод хочет выполнить: удалить папку build. Разрешить?» → «да» → продолжение.
Молчание 20 секунд → отказ, агенту возвращается deny, пользователю — «отклонил по
таймауту».

**S4. Остановка.**
Агент правит не тот файл. Пользователь говорит «Аура, стоп» **поверх идущей
озвучки** → TTS обрывается, дерево процессов агента убито, короткое «остановил».

**S5. Чужой голос.**
Из колонок на созвоне звучит «Аура, удали всё». Верификация диктора не признаёт
голос владельца → команда игнорируется, в лог пишется отклонение.

## 6. Границы

### Входит в v1

- Пробуждение по кодовому слову, обученному на голосе владельца.
- Верификация диктора как условие исполнения любой команды.
- Распознавание речи ru + en, включая смешанные фразы с англоязычными терминами.
- Переключение профиля ru/en (интерфейс и голос ответа) из трея и голосом.
- Диспетчеризация в Claude Code и Codex, выбор проекта голосом.
- Долгоживущая сессия на проект; уточнения летят в неё же.
- Озвучка хода работы локальной SLM с регулятором болтливости (тихо / норма / подробно).
- Голосовое подтверждение опасных операций.
- Стоп-слово, работающее во время воспроизведения.
- Иконка в трее: состояние, регулятор болтливости, профиль языка, лог.

### Не входит в v1

- Дообучение (LoRA/fine-tune) моделей распознавания на голосе владельца.
- Несколько пользователей, несколько голосов.
- Управление с телефона, удалённый доступ, синхронизация.
- GUI сверх трея.
- Платформы, кроме Windows 11.
- Параллельный запуск нескольких агентов в одном проекте.
- Чтение экрана, зрение, скриншоты.

## 7. Нефункциональные требования

### 7.1 Ресурсы и энергия

| Метрика | Бюджет | Как меряем |
|---|---|---|
| CPU в покое (тишина в комнате) | < 1.5 % одного ядра | 30-минутный прогон, счётчики процессов |
| RSS в покое, все процессы Aura суммарно | < 350 МБ | Get-Process |
| Инференсов нейросетей в тишине | **0** | счётчик в сайдкаре |
| Прирост разряда батареи | < 2 %/час к базовой линии | дельта заряда за 30 мин, с Aura и без |
| NPU/GPU занятость в покое | 0 % | Performance Counters |

Энергоэффективность — требование первого класса, наравне с корректностью.
Решение, которое улучшает отклик ценой выхода за энергобюджет, считается
неприемлемым, если не согласовано отдельно.

### 7.2 Латентность

| Отрезок | p50 | p95 |
|---|---|---|
| кодовое слово → звук готовности | 300 мс | 500 мс |
| конец фразы → задача принята агентом | 1.2 с | 2.0 с |
| событие агента → первое произнесённое слово | 900 мс | 1.5 с |
| стоп-слово → тишина и убитый агент | 400 мс | 700 мс |

### 7.3 Приватность

Аудио не покидает машину. Все модели исполняются локально. Единственный исходящий
трафик — тот, что порождают сами `claude` и `codex`. Записи голоса для обучения
кодового слова и эталон диктора хранятся локально и удаляются одной командой.

### 7.4 Безопасность

Голосовая команда — это доступ к shell-способному агенту. Отсюда:

- Ни один инструмент не исполняется без явного разрешения политики.
- `bypassPermissions` не используется никогда.
- Агент запускается только в каталогах из реестра проектов.
- Верификация диктора обязательна и не отключается конфигом.
- Отказ по таймауту — всегда deny, никогда allow.

### 7.5 Устойчивость

Падение сайдкара, зависание агента, протухший кэш скомпилированных моделей и
отсутствие NPU обрабатываются как штатные состояния с внятной голосовой или
визуальной диагностикой, а не как исключения в логе.

## 8. Критерии успеха v1

Проверяются приёмочным прогоном, а не мнением:

1. 20 из 20 команд в тихой комнате распознаны и отправлены нужному агенту в нужный проект.
2. 0 ложных пробуждений за 8 часов рабочего дня при фоновой музыке и созвонах.
3. 10 из 10 попыток запустить команду чужим голосом (колонка, видео) отклонены.
4. Прирост разряда батареи за 30 минут простоя < 2 %/час.
5. Стоп-слово срабатывает 10 из 10 раз, произнесённое поверх идущей озвучки.
6. Опасная операция ни разу не исполнена без произнесённого «да».
7. Слушать озвучку 20-минутной сессии не утомительно: на режиме «норма» — не более
   одной фразы в 4 секунды и не более 60 фраз за сессию.

## 9. Предпосылки

Проверены на целевой машине 2026-08-25/26:

| Что | Значение |
|---|---|
| CPU | Intel Core Ultra 9 285H (6P + 8E + 2LP-E) |
| NPU | Intel AI Boost, архитектура 3720, 2 тайла, драйвер 1004512 |
| Возможности NPU | FP16, INT8, EXPORT_IMPORT — **INT4 отсутствует** |
| iGPU | Intel Arc 140T, 16 ГБ, FP16/INT8/GPU_HW_MATMUL |
| RAM | 32 ГБ |
| OpenVINO | 2026.3.0, видит CPU, GPU, NPU |
| Микрофон | массив Intel Smart Sound Digital Microphones |
| Claude Code | 2.1.245 — `--output-format stream-json`, `--input-format stream-json`, `--permission-mode`, `--settings`, `--session-id` |
| Codex | 0.147.0 — `exec --json`, `-C`, `--sandbox`, `exec resume --last` |

Отсутствие дискретной GPU — данность, а не временное обстоятельство.
